# @bsv-kit/grist

Send grist with photos and poll the mill's answer. It uses `@bsv-kit/bsv` only through its
public exports.

```ts
import { grist } from 'bsv-kit/grist';
```

Lifted from Postern's `src/services/` (`send.ts`, `attachments.ts`, `talk.ts`); Postern's wire
formats are the law. The namespace is a stub until its story lands.
